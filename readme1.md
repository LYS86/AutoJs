# 项目情况

## 开发规范
- 使用kotlin
- 全面使用AndroidX，Android KTX库
- Kotlin Flow 替代 RxJava
- DataStore 替代 SharedPreferences
- 采用 MVVM 架构模式
- 使用 ViewModel 和 LiveData/Flow
- 日志使用timber.log.Timber
- 使用Material Design 3
- 不允许使用弃用的api，除非没有替代方法或者刚需
